# MohammadMdv.github.io

Personal academic website of Mohammad Mahdavi, served at [mohammadmdv.github.io](https://mohammadmdv.github.io).

A single static page (`index.html`) with no build step. Edit it and push to `main` to deploy via GitHub Pages.

- **Typeface:** [Source Serif 4](https://fonts.google.com/specimen/Source+Serif+4), loaded from Google Fonts.
- **Portrait:** add a photo at `images/profile.jpg` (portrait orientation, about 4:5). It appears to the right of the introduction automatically; while the file is missing, the column is hidden.
- **Updating:** each section in `index.html` is marked with an `id` (`education`, `research`, `industry`, `publications`, `projects`, `teaching`, `honors`, `skills`). Copy an existing entry to add a new one, and change the "Last updated" date in the footer.
