# MohammadMdv.github.io

Personal academic website of Mohammad Mahdavi, served at [mohammadmdv.github.io](https://mohammadmdv.github.io).

A single static page (`index.html`) with no build step. Edit it and push to `main` to deploy via GitHub Pages.

- **Typefaces:** [Fraunces](https://fonts.google.com/specimen/Fraunces) for headings and [Inter](https://fonts.google.com/specimen/Inter) for text, loaded from Google Fonts.
- **Portrait:** `images/profile.jpg`, cropped to 4:5. Replace the file to change the photo.
- **Updating:** each section in `index.html` is marked with an `id` (`publications`, `experience`, `education`, `projects`, `skills`, `contact`). Copy an existing entry to add a new one, and change the "Last updated" date in the footer.
